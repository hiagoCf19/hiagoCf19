# Olá, eu sou o Hiago! 👋

**Desenvolvedor Backend no BTG Pactual | Graduado em Análise e Desenvolvimento de Sistemas**

Atuo profissionalmente como desenvolvedor, focando em projetos estratégicos de alta complexidade no setor financeiro. Tenho forte experiência em modernização de sistemas, arquitetura de microsserviços e desenvolvimento *mobile-first*. Trabalho com uma ampla variedade de tecnologias, tanto no frontend quanto no backend, entregando soluções escaláveis, eficientes e seguras.

### 🔭 O que eu ando fazendo:
- 🏦 Atuando como desenvolvedor no **BTG Pactual**, contribuindo para soluções tecnológicas estratégicas e de alta performance no mercado financeiro.
- ⚙️ Trabalhando com **Arquitetura Orientada a Eventos (EDA)** e mensageria (RabbitMQ) para processamento distribuído de alto volume.
- 🤖 Desenvolvendo automações com inteligência artificial, integrando modelos **Gemini** para extração de dados e otimização de fluxos de trabalho.
- 🔒 Focando intensamente em segurança estrutural (implementação de JWT, RLS avançado, 2FA e criptografia AES-GCM).
- 🌱 Priorizando arquitetura limpa, organização e qualidade de código.
